# TAX CONSULTANTS

A professional tax consulting website built with:

- Next.js 14
- TypeScript
- Tailwind CSS
- Prisma
- Supabase
- NextAuth.js
- Resend
- Docker
- Vercel

## Project Status

🚧 Currently under development.

## Development

Install dependencies:

```powershell
npm install
```

Start the development server:

```powershell
npm run dev
```

Open:

http://localhost:3000
